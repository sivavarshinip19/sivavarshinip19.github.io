# Sivavarshini P — Portfolio

Static portfolio site (HTML + CSS + vanilla JS). No build step.

## Deploy on GitHub Pages
1. Create a repo named `sivavarshinip19.github.io` (for a root URL) or any name (e.g. `portfolio`).
2. Upload all files in this folder to the repo root.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`.
4. Live at `https://sivavarshinip19.github.io/` (or `/portfolio/`).

## Edit
- Content: `index.html`
- Colours/fonts: CSS variables at the top of `style.css`
- Resume: replace `assets/Sivavarshini_P_Resume.pdf`
